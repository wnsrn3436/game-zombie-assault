# Zombie Assault

An action game where you fight mutating zombie hordes, switching between a sword and a gun. Made for a GameMaker community event.

<p>
  <img src="docs/screenshots/screenshot-1.png" width="480" alt="Gameplay">
</p>


## How to play

Download from Releases, extract and run. The opening video has to sit next to the game, so extract the whole folder.

Move with WASD, aim with the mouse and attack. Keys 1 and 2 switch between the sword and the gun. A zombie that touches the virus roaming the map mutates. There is a minimap in the bottom left.
